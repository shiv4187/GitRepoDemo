📌 About This Repository
I created this repository to learn, practice, and improve my understanding of Git and GitHub.

The main goal is to get hands-on experience with version control and understand how Git is used in real software development projects.

Adding and tracking files
Committing changes
Writing meaningful commit messages
Creating and working with branches
Switching between branches
Merging branches
Resolving merge conflicts
Pushing changes to GitHub
Pulling changes from GitHub
Cloning repositories
Using .gitignore
Understanding Git history
Creating Pull Requests
Learning basic collaboration workflows
